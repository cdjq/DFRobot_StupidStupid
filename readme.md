# DDSM115 电机例程使用说明
    使用前需要先设置电机ID

## 设置 电机 ID
按照如图所示设置电机对应的id
使用setID.ino 这个函数配置成指定的id

## 使用手柄驱动小车
配置好电机id后
使用stupidStupid.ino 这个函数驱动电机
在Arduino 中下载 PS3_Controller_Host 这个库，或者直接使用离线包中的库放到arduino lib下



## 手柄使用说明

## P3 按键定义
    esp32 上电后 按下p3 进行蓝牙连接，闪烁灯熄灭后连接成功

## 左摇杆方向定义如下
    270-90 度 向前   顺时针 270-->325-->0-->45-->90
    90-270 度 先后   顺时针 90-->135-->180-->225-->270
    推动距离越大速度越大
         0
     325   45
    270      90
     225   135
        180

### 右侧摇杆定义
    左右原地旋转

### 三角形绿色按钮定义
    速度，按一下加一档位速度， 0-4档，默认0档速度
